# عامل واکنشی ساده — مسئلهٔ سویچ نور (محیط 2×2)

پیاده‌سازی یک **عامل واکنشی ساده (Simple Reflex Agent)** در پایتون برای مسئلهٔ سویچ نور در محیط شبکه‌ای 2×2.
**هدف عامل:** خاموش کردن همهٔ خانه‌های روشن.

## الگوریتم

حلقهٔ `ادراک → تصمیم → اجرا` فقط بر اساس ادراک لحظه‌ای (خانهٔ جاری + وضعیت چراغ همان خانه)، بدون حافظه و بدون مدل از بقیهٔ خانه‌ها:

| مرحله | توضیح |
|---|---|
| 1. ادراک (Percept) | مختصات خانهٔ جاری `(x, y)` و وضعیت چراغ همان خانه |
| 2. تطبیق قواعد | بررسی قواعد شرط–عمل به ترتیب؛ اولین قاعدهٔ برقرار برنده است |
| 3. تصمیم (Decide) | برگرداندن عمل قاعدهٔ تطبیق‌یافته |
| 4. اجرا (Act) | تغییر وضعیت چراغ یا جابه‌جایی عامل در شبکه |
| 5. تکرار | دریافت ادراک جدید و ادامه تا رسیدن به شرط پایان |

### قواعد شرط–عمل

- **R1:** اگر چراغ خانهٔ جاری **روشن** است → `TOGGLE` (زدن کلید تا خاموش شود).
- **R2:** اگر چراغ **خاموش** است و خانهٔ جاری **آخرین خانه نیست** → `MOVE` به خانهٔ بعدی در ترتیب ثابت `(0,0) → (0,1) → (1,0) → (1,1)`.
- **R3:** اگر در **آخرین خانه** هستیم و چراغش خاموش است → `HALT` (پایان).

### تضمین درستی

ترتیب بازدید ثابت است، پس هر خانه دقیقاً یک بار بازدید و همان‌جا خاموش می‌شود؛ بنابراین بعد از بازدید خانهٔ چهارم همهٔ چراغ‌ها خاموش‌اند.
حداکثر **۶ عمل** (۴ خاموش‌کردن + ۲ حرکت) + فراخوانی `HALT`.

> نکته: اگر عامل به‌جای R1 کورکورانه همیشه کلید را می‌زد، چراغ‌های خاموش روشن می‌شدند؛ پس شرط `if light` ضروری است.

## اجرا

```bash
python light_switch_agent.py
```

خروجی، وضعیت اولیه و نهایی شبکه، هر گام همراه با قاعدهٔ انتخاب‌شده و عمل انجام‌شده را نشان می‌دهد و در پایان **همهٔ 16 حالت اولیهٔ ممکن** را برای اطمینان از صحت آزمایش می‌کند.
